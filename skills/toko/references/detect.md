# Look before you change anything

Spend a minute reading the project first. Each answer below decides how a later step goes, and a wrong guess (a Tailwind v3 config in a v4 project, a second stylesheet, a dark mode that fights the tokens) is the usual reason an install breaks.

| Find out | Where to look |
|---|---|
| Framework | `package.json` dependencies: `next`, `vite`, `astro`, `@sveltejs/kit`, `nuxt`, `react-scripts`, or plain HTML |
| Package manager | the lockfile: `pnpm-lock.yaml` → pnpm, `yarn.lock` → yarn, `bun.lock`/`bun.lockb` → bun, `package-lock.json` → npm |
| Global stylesheet | Next app router: `app/globals.css` (imported in `app/layout.tsx`). Next pages: `styles/globals.css` in `pages/_app.tsx`. Vite: the CSS imported in `src/main.tsx`/`main.ts`. Astro: a layout's `<style is:global>` or an imported CSS file. SvelteKit: `src/app.css` in `+layout.svelte`. Plain: the `<link rel="stylesheet">` in `index.html` |
| Tailwind version | v4: `@import "tailwindcss"` in CSS and `tailwindcss` 4.x. v3: a `tailwind.config.js/ts` and `@tailwind base;` lines |
| shadcn | `components.json` at the root; `--background`, `--primary` and friends in the global stylesheet; components in `components/ui/` |
| Dark mode today | a `.dark` class (`@custom-variant dark`, `darkMode: "class"`, `next-themes` with `attribute="class"`), a `data-theme` attribute, `prefers-color-scheme` media queries, or none |
| Existing theme variables | custom properties the project defines itself, especially names Toko also uses: `--surface`, `--text`, `--border`, `--ring`, `--shadow-*`. Project rules outside a cascade layer beat Toko's, so they'd silently win |
| Agent rules files | `AGENTS.md`, `CLAUDE.md` (root and nested), `.cursor/rules/` |
| A previous Toko install | a `toko.json` at the root (then it's the Sync job: read sync.md), files starting with `Generated by Toko`, and `<!-- toko:start -->` in AGENTS.md or CLAUDE.md. If both exist, this is an update: read update.md |

Also note how the project builds and checks itself (`build`, `typecheck`, `lint` scripts), so you can run them later.

If the user attached or pasted the files, save each one unchanged. tokens.css is long; check nothing was cut off (its last lines close the `@layer tokens { … }` block) and ask for the rest if it was. If the files aren't anywhere, ask the user to export them from Toko's Export page before going further. Never recreate them from memory.
